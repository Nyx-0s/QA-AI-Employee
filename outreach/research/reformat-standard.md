# Reformat standard — ratified via Dutch Craft sample 2026-09-19

**Applies to:** every sendable draft (33 total incl. the approved sample) and
all 5 nudge follow-ups. Only the sendable body changes; header, verbatim
pain-quote footer, and `APPROVAL:` line are preserved byte-for-byte.

## The five rules

1. **Subject:** 3–6 words, lowercase-feel, names THEIR flow ("Custom quote
   requests, organized") — never product-first, never punctuation-heavy.
2. **Greeting:** "Hello," by default; "Hi <First name>," ONLY where the name
   is publicly listed on their own site (source cited in
   `outreach/research/depth-pass-2026-09-19.md`). Never guessed, never from
   a directory alone.
3. **Body:** 2–3 short paragraphs, ≤90 words total. Para 1 = THEM (their
   page's own words/flow, specific). Para 2 = the task, one sentence, plus
   the human-gate ("nothing goes out without a click from you" idea, in
   plain words). Para 3 = one clear ask (15-minute walkthrough), no urgency.
4. **Sign-off:** "Thanks for your time," / "ConsentArk" /
   "consentarkhe@gmail.com" — exact, every draft.
5. **No artifacts:** no markdown syntax in the sendable body, no em-dashes
   in subject, no "we are a startup/revolutionary/AI-powered" hype.
